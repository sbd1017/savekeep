SaveKeep

Saves

Every save that reaches SaveKeep is kept here once, by its SHA-256, and never changed. The newest few per game are kept; pin a save to keep it for good. Nothing here talks to a console: to go back to a save, download it and restore it with JKSV or Checkpoint (steps below).

Restoring a save

Restoring replaces the save on the console. Make a fresh backup of the current save with the same tool first, so you can change your mind.

Switch, with JKSV

  1. In JKSV, open the game and make a new backup of the current save as a folder (with JKSV's "Export to ZIP" off). Name it restore, for example.
  2. Download main here. On the SD card, replace /JKSV/<game>/restore/main with it. Leave any other files in that folder alone.
  3. In JKSV, select restore and choose Restore. Start the game and check.
  4. If the save came in as a JKSV zip, Original zip is the exact file JKSV made: copy it into /JKSV/<game>/ and restore that instead. The main-only zip is built here and holds nothing but main; the folder method above is the safer choice.

3DS, with Checkpoint

  1. In Checkpoint, select the game and make a new backup, named restore for example.
  2. Download main here. On the SD card, replace /3ds/Checkpoint/saves/<game>/restore/main with it.
  3. In Checkpoint, select restore and choose Restore. Start the game and check.

Copy a backup over FTP

Reads the newest JKSV (Switch) or Checkpoint (3DS) backup straight off the SD card while ftpd runs on the console. Only read commands are ever sent; nothing on the SD card changes. The copy goes into Saves.

  1. Save in the game, then back it up with JKSV or Checkpoint.
  2. Start ftpd on the console and note its IP address and port.
  3. Search, check the suggested backup, then Copy. Tip: search once before making the backup, so the new one stands out even if the console's clock is wrong.

Receive JKSV uploads

Off

JKSV on the Switch can send a backup straight here over Wi-Fi (WebDAV), so you don't need ftpd. Uploads are accepted and nothing else: each one is checked to be a Pokémon save and kept in Saves. JKSV can't read, change or delete anything that is kept.

Set up JKSV (once)
  1. Turn the receiver on here and copy the webdav.json it shows. The password is shown only once; if you lose it, make a new login.
  2. Put the file on the Switch's SD card as sd:/config/JKSV/webdav.json. origin must be this server's IP address and port, with no slash at the end.
  3. Start JKSV. It should say WebDAV started. If it doesn't, check the address, that the receiver is on, and that the Switch has internet access (JKSV checks for it). JKSV's log on the SD card has the details.
  4. In JKSV's settings, turn on Export to ZIP. Current JKSV versions only upload zip backups.

Each time

  1. Save in the game, then close it.
  2. In JKSV, open the game and make a new backup.
  3. Highlight the backup and press ZR to upload it. JKSV's auto-upload setting does this for every new backup.
  4. Check the list below. JKSV reports success even when the upload was refused, so this list is the real answer.

Things to know: the password sits in plain text on the SD card and travels unencrypted over your Wi-Fi. Anyone on your network who has it can add saves, but can't read, change or delete any. Turn the receiver off when you don't need it, or make a new login to cut off the old one. JKSV's own remote list stays empty, so restore from Saves, not from JKSV's remote menu.
